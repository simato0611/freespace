# 「芝生の値段」の調べ方

他人の実績を値踏みするための手順書。SNS・業者資料・論文、どれにも使える。

`scripts/price_the_grass.py` が計算部分を自動でやる。この文書は**何を訊くか**を書く。

---

## 使い方

```bash
python scripts/price_the_grass.py \
  --annual 0.20 --vol 0.06 --win-rate 0.95 --max-dd 0.008 \
  --months 12 --holding-days 1 --trials 1
```

分かっている数字だけ渡せばよい。ボラが分からなければ `--sharpe` を渡す。

---

## 検算できる5つ

### 1. 勝率と Sharpe は両立するか

**正規分布なら、Sharpe が決まれば勝率も決まる。**
月次で Sharpe 1.0 なら勝率は 63%、Sharpe 0.23 なら 53% が理論値である。

申告勝率がそれより**高すぎる**なら、分布が負に歪んでいる——
**小さく勝ち続け、たまに大きく負ける形**である。

該当するもの: キャリー取引、資金調達率アービトラージ、オプション売り、ナンピン、グリッド。

> 実例: 99年の信用キャリーは月次勝率 59% に対し Sharpe 0.23。
> 理論値 52.7% より 6.3ポイント高く、二項検定 p < 0.0001。実際の歪度は −0.98 だった。

**「勝率が高い」は長所ではなく、危険信号になりうる。**

### 2. 最大ドローダウンは小さすぎないか

その Sharpe・その期間なら、DD はこのくらい出るはず——をモンテカルロで出す。
申告 DD がそれより**極端に小さい**なら、次のどれかである。

- (a) 期間が短くて、まだ悪い局面が来ていない
- (b) 分布が正規でない（左の裾が未実現）
- (c) 申告が正確でない

**(a) が一番多い。**

### 3. 運と実力を見分けられる期間か

Sharpe S を「偶然ではない」と言うには、おおよそ **(2/S)² 年**かかる。

| 申告 Sharpe | 必要年数 |
|---:|---:|
| 3.0 | 0.4年 |
| 2.0 | 1.0年 |
| 1.0 | 4.0年 |
| 0.5 | 16年 |

Sharpe が低いほど、証明に時間がかかる。**逆に言えば、
高い Sharpe を主張するほど短期間で検証できてしまう**ので、
「Sharpe 3 を1年」は数字としては成立する。だからこそ他の項目で見る。

### 4. 何通り試した中の最良か

N 通り試して最良を選べば、**実力ゼロでも見かけの Sharpe は上がる**。
その分を差し引く。

> 実例: 我々の戦略は Sharpe 1.16 だが、327試行の中の最良である。
> 割引後は **−0.30**。これを隠さず申告している。

**この項目を訊いて答えられない相手の実績は、値踏みできない。**

### 5. コストの余裕はあるか

保有期間が短いほど、成績はコストに食われやすい。
「この成績を消し飛ばす片道コスト」を出す。

| 損益分岐コスト | 判定 |
|---|---|
| 片道 5bp 未満 | 実効スプレッドが少しずれるだけで消える |
| 片道 20bp 以上 | 相当な余裕がある |

---

## 最も重要なこと — 短い実績は「評価できない」

12か月の実績で「月次勝率95%、Sharpe 3.3」を検算すると、
理論値との差 11.8ポイントに対して **p = 0.70**。有意差なしになる。

しかしこれは「歪んでいない」という意味ではない。
**12か月では ±21ポイントの差まで検出できない**からである。
この差を有意に判定するには **39か月（3.2年）** かかる。

> **短い実績は「良い」でも「悪い」でもなく、「判定不能」である。**

SNS の実績報告の大半がこれに該当する。**判定不能なものを良いと解釈しないこと。**

## 数字で検算できないこと（必ず別途訊く）

| 項目 | 訊き方 |
|---|---|
| **危機を経験したか** | 「2022年5月（LUNA）と11月（FTX）はどうでしたか」 |
| **キャパシティ** | 「運用額はいくらですか。10倍にしても同じ成績が出ますか」 |
| **生存者バイアス** | 「同じ手法で失敗した人を知っていますか」 |
| **執行の前提** | 「メイカー手数料はいくらですか。約定率は」 |
| **カウンターパーティ** | 「取引所が飛んだらどうなりますか」 |

**最初の質問が一番効く。**暴落を通過していない実績は、
「まだ通過していない」という情報しか持っていない。

---

## 判定の型

3つに分けるだけでよい。**「良い」を安易に使わない。**

| 判定 | 条件 |
|---|---|
| **判定不能** | 期間が足りない（大半がこれ） |
| **危険信号あり** | 勝率が Sharpe に対して高い / DD が小さすぎる / コスト余裕なし / 試行回数不明 |
| **検算を通過** | 上のどれにも当たらず、危機を1回以上通過している |

**「検算を通過」は「儲かる」という意味ではない。**
「主張が数字として成立している」というだけである。そこからが検討の開始点になる。

## この道具を自分にも向けること

我々の戦略を同じ物差しに乗せると、**2つの疑問点が出る。**

```
✗ 統計的な確証に 3.0 年必要だが実績は 1.2 年
✗ 試行回数を考慮すると Sharpe がゼロ以下になる
```

**自分の戦略に厳しく使えない道具は、他人の戦略にも使えない。**
まず自分に向けてから、他人に向けること。
