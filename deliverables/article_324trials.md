# 暗号資産の自動売買を324回検証して、ようやく分かったこと

## この記事に書いてあること

半年かけて、暗号資産のアルゴリズム取引を **324通り** 検証しました。
採用できたのは **1つ** です。残りの323は失敗です。

この記事は、その323の失敗の記録です。成功例ではありません。

なぜ失敗を書くかというと、**失敗の理由の方が再利用できるから**です。
「このパラメータで勝てました」は他人には使えませんが、
「この検証方法だと自分を騙します」は誰にでも使えます。

書いてあるのは次の5つです。

1. 1分足で勝てない理由が、算数で3行で出る
2. 使っていた公開データが壊れていた（標準的なチェックを全部すり抜けた）
3. 強化学習は単純なルールに2回負けた
4. 92年分のデータで見た「トレンドフォローの正体」
5. 自分を騙さないための検証の作法

---

## 1. 1分足で勝てない理由は、算数で出る

最初にやったのは、強化学習で1分足〜15分足のスキャルピングを作ることでした。
学習が回り始める前に、次の計算をして手が止まりました。

**損益分岐Sharpe**という考え方があります。
「コストを払った上でプラスにするには、コスト前でどれだけの精度が必要か」を出す計算です。

片道コストを `c`、判断間隔を `T` 分、1回の判断ごとに建玉を入れ替えるとします。
年間の取引回数は `525600 / T` 回。年間コストは `2c × 525600 / T`。
これをリターンのボラで割ったものが、必要な「グロスSharpe」です。

実際に計算すると、こうなります（片道2.5bp、年率ボラ60%を仮定）。

| 判断間隔 | 必要なグロスSharpe |
|---|---:|
| 5分 | **106** |
| 15分 | **35** |
| 60分 | 8.9 |
| 240分 | 2.2 |
| 1440分（日次） | **0.7** |

Sharpe 106 は、存在しません。世界最高のヘッジファンドでも 3〜4 です。

**5分足でスキャルピングして勝つには、人類が到達したことのない精度が必要**ということです。
これは実装の巧拙の問題ではありません。

実際に測ってもそうでした。1分足のOHLCVから作れる特徴量の予測力（IC）は 0.01〜0.02 で、
損益分岐に必要な水準の **1/2〜1/30** しかありませんでした。

そして決定的だったのが次の結果です。

> **取引コストを完全にゼロにしても、2.1年のアウトオブサンプルで Sharpe +0.11**

コストを消しても儲からない。つまり損失の直接原因はコストですが、
**根本原因は「1分足に情報が無い」こと**でした。

短期売買を考えている人は、まずこの計算をしてください。
コードを書く前に、勝てるかどうかが分かります。

## 2. 使っていたデータが壊れていた

これがこのプロジェクトで一番大きな学びです。

ある大手取引所の公開ヒストリカルデータ（2012年〜、1分足）を使って検証していました。
数か月後、別の取引所のデータを追加したときに、おかしなことに気づきます。

- 価格の水準は、他のソースと **±1bp** で一致する
- ボラティリティも **±2%** で一致する
- 欠損なし、重複なし
- 統計量はどこを見ても正常

**しかし、時間足リターンの相関がほぼゼロでした。**

同じBTCの同じ時刻の1時間リターンが、2つのソースで無相関。
片方は「その時刻に何が起きたか」を記録していませんでした。
価格の分布は正しいのに、**時刻と値動きの対応が壊れていた**のです。

これがどれだけ厄介かというと、

- 欠損チェック → 通る
- 重複チェック → 通る
- 価格水準の検算 → 通る
- ボラの検算 → 通る
- バックテストを回す → 「それらしい」結果が出る

**全部通ります。** そして短期の予測力の測定結果が、まるごと無意味になっていました。

### 検出方法は単純です

**同じ資産の、独立した2つのソースを突き合わせる。** それだけです。

健全なら時間足リターンの相関は 0.99 以上になります。0.9 を下回ったら疑ってください。
（建て通貨が違う場合は0.95程度まで落ちますが、それでも0.8を下回ることはありません）

```python
# 2つのソースの時間足リターン相関を見る
a = load("source_a.parquet").resample("1h").last()
b = load("source_b.parquet").resample("1h").last()
ret_a = np.log(a["close"]).diff()
ret_b = np.log(b["close"]).diff()
print(ret_a.corr(ret_b))   # 0.99以上なら正常、0.9未満なら破損を疑う
```

さらに**年ごとに見てください**。全期間で0.95でも、特定の年だけ0.3ということがあります。
部分的な破損が一番危険です。

私は正常なデータで測り直しました。予測力は当初の報告より2〜3倍高く出ましたが、
**損益分岐には遠く及ばず、結論は変わりませんでした**。それでも、
気づかなければ嘘の数字を信じ続けていたことになります。

**新しい価格データを入れたら、必ず独立ソースと突き合わせてください。**

## 3. 強化学習は、単純なルールに2回負けた

このプロジェクトは元々「強化学習でトレード戦略を作る」ものでした。
PPOを実装し、以下を全部やりました。

- GAE、方策と価値のトランク分離、報酬スケーリング
- 一様混合による探索フロア（エントロピー崩壊対策）
- 適応的エントロピー目標
- コストカリキュラム（学習初期はコストを軽くし、徐々に本番水準へ）
- 行動クローニングによるウォームスタート

技術的にはちゃんと動きました。学習も収束しました。

**そして、5/14/30/60日モメンタムの平均という「小学生でも書ける規則」に負けました。**

| | Sharpe（4フォールド平均） |
|---|---:|
| PPO | **+0.14** |
| 単純ルール | **+0.67** |

RLが勝ったのは4フォールド中1つだけです。

1回目は「データが壊れていたせいかもしれない」と思い、正常データで再検証しました。
**2回目も同じ結果**でした。

### なぜ負けるのか

理由ははっきりしています。

**シグナルが1本の特徴量の単調関数だからです。**

「モメンタムが強いほど大きく建てる」という関係が正しいなら、
それをそのまま書いたルールが最適です。RLはその関数を**データから推定し直す**ので、
推定誤差と分散を足すだけになります。

RLが効くのは、状態空間が複雑で、報酬が遅延し、行動が環境を変える問題です。
「価格系列を見て建玉を決める」は、そのどれでもありません。

**RLを使う前に、まず単純なルールを書いて比べてください。**
それが超えられないなら、RLは要りません。

## 4. 92年分のデータで見た「トレンドフォローの正体」

暗号資産のデータは長くても6年しかありません。6年でSharpe 1.0が出ても、
それが6年ぶんの幸運なのか普遍的な性質なのかは区別できません。

そこで **1926年からのデータ（92年分）** で、同じ原理を検証しました。
大恐慌、第二次大戦、70年代インフレ、ブラックマンデー、ITバブル、リーマンを全部含みます。

### 結果1: 92年間、一度も死ななかった

12か月モメンタムを株式市場ファクターに当てた結果です。

| 期間 | Sharpe |
|---|---:|
| 1926-1956 | +0.68 |
| 1957-1987 | +0.10 |
| 1988-2018 | +0.62 |

3つの独立した時代すべてでプラス。符号が反転する時代がありません。

### 結果2: でもSharpeでは買い持ちに勝てない

| 系列 | 買い持ち | トレンド |
|---|---:|---:|
| 株式市場 | **0.49** | 0.46 |
| バリュー | **0.36** | 0.30 |
| 高格付社債 | **1.08** | 0.74 |

**5系列中4系列で、トレンドは買い持ちに負けるか同等**でした。

「トレンドフォローは儲かる魔法」ではありません。少なくとも単体では、
ただボラ調整して持っているのと大差ありません。

### 結果3: では何が違うのか

同じSharpeなのに、**最大ドローダウンが2〜3割小さく、歪度が改善します。**
ある系列では歪度が **−1.63 → +0.86** と符号が反転しました。
「たまに大きく損する」形が「たまに大きく勝つ」形に変わります。

そして決定的なのがこれです。

| 局面 | 買い持ち | **トレンド** |
|---|---:|---:|
| **大恐慌 1929-1932** | **−48.9%** | **+9.0%** |
| 第二次大戦 1939-1945 | +133.3% | +109.9% |
| **70年代インフレ 1973-74** | **−52.7%** | **+60.5%** |
| ブラックマンデー 1987 | −4.7% | −3.2% |
| **ITバブル崩壊 2000-02** | **−37.8%** | +0.8% |
| **リーマン 2008-09** | **−40.5%** | **+27.5%** |

**92年間の株式4大暴落すべてで、買い持ちが38〜53%失ったときにトレンドはプラスでした。**

上げ相場では買い持ちに少し劣ります（戦時の+133% vs +110%）。
その代わり、**暴落で逆を向きます。**

### トレンドフォローの正体

**これは「儲ける道具」ではなく「生き残る道具」です。**

期待リターンを上げるのではなく、**リターンの分布の形を変える**のが仕事です。
左の裾（大暴落）を切って、その代金を上げ相場の一部で払っています。

### そして、暗号資産で価値が最大になる理由

| | 買い持ち | トレンド |
|---|---|---|
| 伝統的資産 | Sharpe 0.49（DD −66%） | 0.46（DD −46%） |
| **暗号資産** | Sharpe 0.31〜0.74（**DD −70〜−96%**） | **1.13（DD −14%）** |

伝統的資産では買い持ちとトレンドで大差ありません。

**暗号資産が特別なのは、買い持ちの崩れ方が壊滅的だからです。**
DOGEを持っていた人は92%減を、SOLは96%減を経験しています。
100万円が4万円になる区間を通ります。

だから同じトレンド則の恩恵が、桁違いに大きくなります。

## 5. 自分を騙さないための検証の作法

324試行やって身についた作法を書きます。全部、痛い目を見て覚えたものです。

### (1) ホールドアウトを封印し、使うのは1回だけ

検証を始める前に、直近の期間（このプロジェクトでは2025年以降）を**完全に隔離**します。
設計中は絶対に見ません。全部固まってから、**1回だけ**当てます。

**結果が悪くても、そこでパラメータを触ってはいけません。**
触った瞬間、その期間はもう検証区間ではなくなります。

### (2) 独立した2つ以上の「時代」で検証する

これが一番効きました。実例を出します。

BTCのトレンドを他の銘柄に当てるという案を検証したときの結果です。

| BTCの重み | 時代B（2020-2024） | 時代A（2017-2020） |
|---:|---:|---:|
| 0.00（現行） | 1.779 | **1.723** |
| 0.30 | **1.870** | **1.528** |

時代Bだけ見れば **+0.09の改善**で、採用したくなる形をしています。
しかし時代Aでは **−0.20の悪化**。方向が逆です。

**時代Bのデータしか持っていなければ、確実に採用していました。**

同じパターンを何度も見ました。出来高で条件づけする案は12通り試して、
**両方の時代で同符号の改善が1つもありませんでした**。
片方で改善する設定は、必ずもう片方で悪化します。

**物語はいくらでも作れます。「出来高が増える局面ほどトレンドが効く」——
もっともらしいですよね。でも再現しません。**

### (3) 試行回数を正直に数える

Deflated Sharpe Ratio という指標があります。
「N回試して最良を選んだ」という選択バイアスを補正して、
「真のSharpeがプラスである確率」を出します。

**この N を正直に数えてください。**

失敗した試行、途中でやめた試行、パラメータをちょっと変えただけの試行、全部です。
「採用しなかった試行は数えない」は、探索の自由度を過小申告する典型的なごまかしです。

私のプロジェクトは324試行で、Deflated Sharpe は **0.028** です。
採用ゲート（0.95）には全く届きません。**それを隠さずに書いています。**

### (4) パラメータを格子で全数検査する

「そのパラメータは当てはめじゃないの?」への答え方です。

私の戦略には探索で選んだ数字が3つありました。
その周辺を格子状に64通り全部回しました。

- **64構成すべてが、両方の時代で勝った**（最悪でもSharpe 1.37）
- 現行値の順位は **64中21位（上位31%）**

**当てはめていたなら上位数%に来ているはずです。** 中位だったということは、
選択の余地が実質的に無かった（どれを選んでも勝つ）ということです。

これは強力な反証です。逆に、格子の中で自分の設定だけが突出しているなら、
それは当てはめを疑うべきサインです。

### (5) 「改善幅」の基準を先に決める

Sharpeの推定誤差は、5年のデータで **±0.4** 程度あります。
つまり **+0.04の改善は、何の意味もありません。**

私は「両方の時代で+0.15以上」を採用条件として**先に固定**しました。
そして何度も、+0.10前後の惜しい候補を落としました。

**基準を後から緩めたら、それまでの全部が無意味になります。**

## 結局、何が残ったのか

324試行のうち、生き残ったのは1つだけでした。

**5/14/30/60日モメンタムの平均を、複数銘柄に、両建てで、等リスク配分する。**
それだけです。特別なことは何もしていません。

封印していた15か月（2025年1月〜2026年3月）の成績です。

| | 戦略 | 同じ5銘柄を買い持ち |
|---|---:|---:|
| Sharpe | **+1.06** | — |
| 年率リターン | **+19.0%** | **−32.2%** |
| 最大ドローダウン | **−8.5%** | **−56.2%** |
| 月次勝率 | 60% | — |
| BTCとの相関 | −0.42 | 1.00 |

**買い持ちが −36.6%（累積）だった15か月で、戦略は年率 +19.0% でした。**
当てたからではありません。10月に全面ショートへ転じたからです。

そして正直に書いておくべきこと。

- **ライブ実績はゼロです。** 全部シミュレーションです
- Deflated Sharpe は 0.028 で、統計的な確証には期間が足りません
- 実運用の期待値は Sharpe **0.5〜0.8** と見るべきです（未知の摩擦は必ずマイナスに出ます）
- 中身は公知のファクター（時系列モメンタム）で、独自性はありません

### 一番の収穫

半年かけて、私が本当に手に入れたのは戦略ではありませんでした。

**「自分が何を知らないか」を、数字で言えるようになったこと**です。

- 1分足では勝てない → 損益分岐Sharpe 106
- RLは要らない → 単純ルールに0.14 vs 0.67
- データを疑え → 独立ソース相関がゼロだった
- 銘柄を増やしても限界がある → 有効独立ベット数2.0
- トレンドは儲ける道具ではない → 92年で買い持ちと同等、ただし暴落で逆を向く

**この5つを知らないまま実弾を入れていたら、確実に溶かしていました。**

323の失敗は、その意味では全部必要でした。

## おまけ: これから始める人へ

順番だけ書いておきます。

1. **最初にコスト計算をする。** 損益分岐Sharpeを出す。話はそれからです
2. **データを疑う。** 独立ソースと突き合わせる。これをやらないと全部が無意味になりえます
3. **単純なルールを先に書く。** それが基準線です。機械学習はその後
4. **ホールドアウトを封印する。** 使うのは1回だけ。悪くても触らない
5. **2つ以上の独立した時代で検証する。** 片方だけ良い案は、必ず落とす
6. **試行回数を正直に数える。** ここでごまかすと、統計的な主張が全部嘘になります

一番大事なのは4と5です。

**バックテストで良い数字を出すのは簡単です。難しいのは、その数字を信じないことです。**
