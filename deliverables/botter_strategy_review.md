## 1. 戦略ファミリー別の評価

### ① 資金調達率アービトラージ（Funding Rate Arbitrage / ベーシス取引）

**仕組み**: 現物をロング、無期限先物を同額ショート。価格変動リスクを消したうえで
資金調達率（8時間ごとの支払い）を受け取り続ける。

| 項目 | 内容 |
|---|---|
| **学術的裏付け** | A: 中〜高。無期限先物の資金調達メカニズムは複数の論文で分析されている |
| **報告リターン（A）** | CEX/DEX の実証研究で、リスク・リターン特性を分析した査読論文あり |
| **報告リターン（B）** | 年 8〜20%（強気相場）、0〜5%（横ばい）、**弱気相場ではマイナス** |
| **必要インフラ** | 現物と無期限先物の両方。同一取引所が望ましい |
| **必要資本** | 中（両建てなので名目の2倍の資金が要る） |
| **レイテンシ要求** | **低**（8時間ごとの判断で足りる） |

**最大の注意点**: これは**アービトラージではなくキャリー取引**です。
資金調達率がプラスである限り儲かり、マイナスになると払い続けます。

- 2022〜2023年、Binance の BTC 資金調達率は **20〜25% の期間でマイナス**でした
- 「年8〜20%、最大DD 0.8%」という業者の数字は**強気相場を切り取ったもの**です
- **リターンの分布が「普段は小さく勝ち、たまに大きく負ける」形**——
  つまり我々が92年の検証で「トレンドフォローが避けている形」そのものです

**日本の個人にとっての実現可能性**: △
GMOコインのレバレッジ取引には、対応する「現物と無期限先物のペア」がありません。
海外取引所（Binance / Bybit）が必要で、税務・カウンターパーティリスクが別途発生します。

### ② マーケットメイク（板に指値を並べてスプレッドを取る）

**仕組み**: 買い指値と売り指値を同時に出し、両方約定すればスプレッドが利益。
在庫が偏らないよう価格を調整し続ける。

| 項目 | 内容 |
|---|---|
| **学術的裏付け** | **A: 最も高い。** Avellaneda & Stoikov (2008) "High-frequency trading in a limit order book" が理論的基礎 |
| **理論の中身** | 在庫リスクを抑えるため価格を歪め、期待効用を最大化するスプレッドを解析的に導出 |
| **必要インフラ** | **板情報のリアルタイム取得、低レイテンシ発注、手数料階層（メイカー手数料マイナスが理想）** |
| **必要資本** | 中〜大 |
| **レイテンシ要求** | **高**（ミリ秒単位の競争） |

**最大の注意点**: **逆選択（adverse selection）**です。
あなたの指値に約定してくれるのは、多くの場合「あなたより情報を持っている相手」です。
研究では、市場価格が本源的価値から乖離しているときほど逆選択のコストが高いと示されています。

AMM（DEX）の流動性提供に関する研究では、**受動的な流動性提供者は逆選択で損をしており、
固定の手数料ではそれを埋め合わせられていない**という結果が出ています。

**日本の個人にとっての実現可能性**: △〜✗
GMOコインのレバレッジ取引は**GMOが相手方**なので、板に指値を並べる形式ではありません。
実行するなら海外取引所か、国内の板取引所（bitFlyer / bitbank）になります。
そしてメイカー手数料の優遇を受けられない個人は、プロと同じ土俵で不利を背負います。

### ③ 三角アービトラージ・取引所間アービトラージ

**仕組み**: 同一資産の価格差（取引所間）、または通貨ペアの循環（A→B→C→A）で
理論上リスクなしの利鞘を取る。

| 項目 | 内容 |
|---|---|
| **学術的裏付け** | **A: 高い（ただし結論はネガティブ寄り）** |
| **実証結果（A）** | 三角アービトラージは **94.97% の確率で利益**。ただし平均純リターンは **9.3ベーシスポイント**（0.093%） |
| 別の研究（A） | 1週間で 4,879 機会を検出。**大半は 0〜0.025% の利幅** |
| さらに別の研究（A） | 20bp 以上の乖離は観測の 17%。しかし**上位機会のうちコスト控除後にプラスなのは 40% のみ** |
| **必要インフラ** | 複数取引所への同時接続、極低レイテンシ |
| **レイテンシ要求** | **極めて高い** |

**結論**: 論文のタイトルが結論を言っています——
**"Wish or reality? On the exploitability of triangular arbitrage"**（願望か現実か）。

利幅 9.3bp に対して、往復の手数料・スリッページ・送金コストを払うと残りません。
**個人が後発で参入して勝てる領域ではありません。**

### ④ 統計的アービトラージ・機械学習による予測

**仕組み**: ペア取引、ファクターモデル、LSTM/Transformer による短期予測。

| 項目 | 内容 |
|---|---|
| **学術的裏付け** | A: 論文は大量にある。**ただし再現性に強い疑問** |
| **報告リターン（A）** | LSTM/GRU のアンサンブルで**コスト控除後 年率 Sharpe 3.23 / 3.12** という報告あり |
| **必要インフラ** | 中（時間足〜日足なら個人でも可能） |

**ここは特に注意が必要です。**

Sharpe 3.2 という数字は、**世界最高峰のヘッジファンドの水準**です。
それが公開された論文で報告されている場合、次のいずれかを疑うべきです。

1. **出版バイアス** — うまくいかなかった実験は論文になりません
2. **試行回数の未申告** — 何通り試して最良を選んだかが書かれていない
3. **コストモデルが甘い** — 実効スプレッドや板の厚みを織り込んでいない
4. **アウトオブサンプルの汚染** — ハイパーパラメータ調整に検証期間を使っている

**私たち自身が324試行かけて、まさにこの領域を検証し、再現できませんでした。**
1〜15分足では損益分岐 Sharpe が 35〜106 必要で、実測の予測力（IC 0.01〜0.02）は
その1/2〜1/30 でした。コストをゼロにしても Sharpe +0.11 でした。

**論文の Sharpe 3.2 を信じる前に、自分のデータで再現してください。**
再現できないなら、それは論文の条件が特殊だったということです。

### ⑤ 清算カスケード（ロスカット狩り）

**仕組み**: レバレッジ建玉が集中する価格帯を推定し、強制清算の連鎖を先回りする。

| 項目 | 内容 |
|---|---|
| **学術的裏付け** | A: 低〜中。メカニズムの分析は進んでいるが、**予測可能性には否定的な結果** |
| **実証結果（A）** | カスケードの開始は**唐突で、事前の警告シグナルは一貫しない** |
| メカニズム（A） | 開始後の強制売りの **88% が30分以内**に発生。建玉は 25〜70% 消える |
| **必要インフラ** | リアルタイム建玉データ、清算価格帯の推定、低レイテンシ |

**結論**: 「起きた後の30分」は予測可能ですが、**「起きるかどうか」は予測できない**
というのが現在の研究水準です。事後的な説明はできるが事前予測はできない、という典型例です。

## 3. 調査から得られた結論

### (1) 「実績のある方法」は確かに存在します。ただし条件付きです

学術的に最も裏付けが強いのは**マーケットメイク**（Avellaneda-Stoikov 2008）です。
しかしそれは「理論が正しい」という意味であって、
**「あなたが実行して勝てる」という意味ではありません。**
必要なのはインフラと手数料階層であり、それを持つ相手と競争することになります。

### (2) 個人が現実的に狙えるのは2つだけです

- **資金調達率アービトラージ**（低レイテンシ不要、学術的裏付けあり）
- **中期トレンドフォロー**（既に持っている。92年で検証済み）

他は全て、レイテンシ・インフラ・情報の競争であり、**後発の個人が勝てる構造ではありません。**

### (3) 最も重要な発見

**資金調達率アービトラージとトレンドフォローは、リスクの形が正反対です。**

| | 普段 | 危機時 |
|---|---|---|
| 資金調達率アービトラージ | 小さく勝ち続ける | **大きく負ける**（負の歪度） |
| トレンドフォロー | 小さく負けることが多い | **大きく勝つ**（正の歪度） |

92年の検証で分かったのは、**トレンドフォローは「たまに大きく損する形」を
「たまに大きく勝つ形」に変える道具**だということでした（歪度 −1.63 → +0.86）。

資金調達率アービトラージは、その逆をやっています。
**普段の安定した収益は、危機時の大損の対価として受け取っているもの**です。
「最大DD 0.8%」という数字は、**まだ危機が来ていない期間**のものです。

**この2つを組み合わせるなら、それは分散ではなく相殺です。** 慎重に設計してください。

## 4. 次にやるべきこと（具体的な手順）

もし資金調達率アービトラージを検証するなら、**我々が324試行で確立した作法をそのまま適用できます。**

1. **資金調達率の履歴データを取得する**（Binance / Bybit の公開APIで取れます）
2. **手数料・スリッページ・借入金利を全部入れたコストモデルを作る**
   （これを甘くすると、必ず嘘の結果が出ます）
3. **2つの独立した時代で検証する**（2019-2021 と 2022-2024 は相場環境が正反対）
4. **弱気相場を必ず含める**（2022年は資金調達率の20〜25%がマイナス）
5. **ホールドアウトを封印し、1回だけ使う**
6. **試行回数を正直に数える**

`scripts/sleeve_lab.py` と `scripts/gmo_validate.py` の枠組みがそのまま使えます。
**必要なのは資金調達率のデータだけです。**
